① 嵌入到 AI 讲题页面

使用 iframe 引入（mode=embed 会隐藏演示控制条，只保留场景与进度）

<iframe src="knowledge-treasure-demo.html?mode=embed&total=6"
        style="width:100%;aspect-ratio:16/9;border:0;border-radius:16px"></iframe>

② 在父页面控制进度（postMessage）

学生每次答题后，把结果告诉 demo

const kt = document.querySelector('iframe').contentWindow;
kt.postMessage({target:'knowledge-treasure', type:'answer', correct:true},  '*');  // 学生答对
kt.postMessage({target:'knowledge-treasure', type:'answer', correct:false}, '*');  // 学生答错
kt.postMessage({target:'knowledge-treasure', type:'reset'},                 '*');  // 重新开始
kt.postMessage({target:'knowledge-treasure', type:'setProgress', value:3},  '*');  // 直接跳到第 3 题进度

③ 监听进度与通关事件

window.addEventListener('message', e => {
  if (e.data && e.data.source === 'knowledge-treasure' && e.data.type === 'progress') {
    console.log('进度', e.data.progress, '/', e.data.total, e.data.complete);
  }
});

④ 同页面直接调用（JS API）

KnowledgeTreasure.answer(true);              // 答对
KnowledgeTreasure.answer(false);             // 答错
KnowledgeTreasure.reset();
KnowledgeTreasure.setProgress(3);
KnowledgeTreasure.onComplete = () => { /* 通关回调 */ };

参数：?total=6 设置题目数（3~12），?mode=embed 嵌入模式。
